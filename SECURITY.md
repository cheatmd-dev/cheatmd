# Security Policy

CheatMD is a command-line tool that builds and runs shell commands from your
Markdown cheatsheets. Selecting a cheat can execute shell commands, and
installed cheat packs are third-party content — only use cheats and packs you
trust.

## Reporting a vulnerability

Please report security issues privately by opening a GitHub security advisory
for this repository:

https://github.com/cheatmd-dev/cheatmd/security/advisories/new

Include:

- CheatMD version (`cheatmd --version`)
- Operating system and shell
- Steps to reproduce
- Relevant logs or error messages, with private cheat content removed

Please do not open a public issue for security reports.
